# Hemmiles 30-loop research programme (started 2026-10-21)

Source brief: ChatGPT-prepared plan pasted by founder 2026-10-21 (preliminary public-site review). Findings there are **hypotheses to verify**, not established facts.

## Rules
- Each loop = one work package. A loop is done when its evidence + deliverable file exist in `loops/LNN-<slug>.md`. Tick cadence is 2 min; a loop may take more than one tick of wall-clock, but only one loop is advanced per tick.
- Reuse earlier work first (MCP repo PRs #2-#21, hemmileswebsite branches `seo/*`, `plan/*`, `fix/*`). Do not duplicate.
- Evidence rules: every fact carries source URL/file + retrieval date. No invented search volumes, rankings or forecasts. Label illustrative data. Do not invent company/legal facts, retention periods or contract terms.
- Inventory rule: every URL list states its source: live sitemap / partial sitemap / static fallback / source route / internal link / search discovery.
- Hemmiles-only: no Meru/HGC/hellocrm cross-mentions in Hemmiles deliverables.
- No site/code changes in this programme. Research + specs + briefs only.
- Status vocabulary tracked separately: researched / drafted / implemented / merged / deployed / measured.

## Immediate owner task (not a loop)
Privacy + Terms pages contain template wording / missing legal identity. Owner (founder/legal) to supply facts; research must not invent them.
